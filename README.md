# AI Arena

AI Arena is a full stack AI-powered web application built using React, TypeScript, Node.js, Express, and MongoDB.

The project provides authentication, AI chat functionality, arena battle features, and file upload support with a modern responsive UI.

---

## Features

- User Authentication with JWT
- Secure Login & Registration
- AI Chat System
- Arena Battle Interface
- File Upload Functionality
- REST API Integration
- Responsive Frontend UI
- TypeScript Backend & Frontend

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt
